# 验证记录

整理日期：2026-09-26。验证运行于 CPU、Python 3.12、PyTorch 2.7.0、Transformers 4.57.1。

## 自动测试

```bash
python -m pytest -q
```

63 项测试通过，覆盖以下内容：

- 完整词表反向 KL 的方向、mask、梯度与数值稳定性；教师和基础模型冻结；只有编辑阶段可以增加记忆槽。
- ZsRE 自回归 token 指标、原模型输出 locality；UnKE 原生 BLEU、ROUGE recall、子问题宏平均、语义相似度边界与 N/A locality。
- MQuAKE 官方划分、训练事实去重、测试事实隔离、三问别名匹配、冲突案例单独汇总；从逐题预测重算分数。
- 数据哈希、保持池隔离、历史重放；完整状态检查点、损坏拒绝、互斥锁、训练和评测中断恢复。
- 将随机初始化的小型 Qwen 与 tokenizer 保存成本地模型，通过实际模型加载入口完成两条编辑、评测、产物哈希校验和恢复；分别覆盖 baseline 与 preserve。已完成运行恢复时不重复加载模型。

UnKE 的自动测试使用受控句向量或受控相似度来验证计算和聚合，不需要下载 MiniLM。它们不构成真实 MiniLM 或 Qwen7B 的性能评测。

源码包和 wheel 均已构建成功。将 wheel 安装到独立目录后，在仓库外验证了运行、重算、数据准备、MQuAKE 准备和下载五个命令行入口。

## 与整理前代码比较

在相同 CPU 随机种子、两层小型 Qwen 和三条连续编辑上，分别比较 ZsRE 与 UnKE token 化路径、baseline 与 preserve，共四种组合。每一步的监督损失、OPD 损失、codebook 键和值、标签、全局随机数状态及学生 rollout 随机数状态均逐项完全相等。

这个检查确认移除未启用的 LoRA／压缩代码没有改变已使用路径的计算；不保证不同硬件、精度或库版本间逐位一致。整理前源码和实验文件不作为本仓库依赖。
